# AWS

A concise collection of the most useful AWS concepts for day-to-day work: compute, storage, networking, and serverless.

How to use this folder
- Read `aws-core-services.md` to understand the building blocks.
- Dive into `aws-networking.md` when you plan your first VPC.
- Use `aws-serverless.md` for quick serverless prototypes.

Note: Always double-check which AWS region you're operating in — it's a common source of confusion and mistakes.
