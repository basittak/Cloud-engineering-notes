# Linux

This folder collects the Linux essentials that every cloud engineer leans on: navigation, file permissions, services, and scripting.

How to use this folder
- Read `linux-basics.md` and practice the commands in a VM or cloud instance.
- Use `shell-scripting.md` to automate small repetitive tasks—start with backups or simple health-check scripts.

Pro tip: Keep a small VM or cloud instance as your sandbox. It’s OK to break things there; that’s where you learn fastest.
