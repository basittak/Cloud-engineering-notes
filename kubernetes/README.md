# Kubernetes

Kubernetes runs production workloads at scale. The notes here are intentionally short and focused on what you need to deploy and debug apps.

How to use this folder
- Start with `kubernetes-basics.md` to learn core primitives.
- Follow `k8s-networking.md` when exposing services or troubleshooting ingress.

Suggestion: Run a local cluster with `kind` or `minikube` for experiments before touching a managed cluster.
