# Interview Prep — Common Questions (Concise)

Summary

A short list of common cloud engineering interview questions to practice across topics.

Questions

- Design: How would you design a highly available web app in AWS? (talk VPC, subnets, ALB, autoscaling, RDS/Aurora, backups)
- Networking: Explain CIDR and how you'd split a /24 into 4 subnets.
- Security: How do IAM roles differ from policies? How to implement least privilege?
- Containers: How do Docker images and Kubernetes deployments differ?
- Automation: How do you handle infra changes via CI (terraform plan/apply)?

Practice tips

- Answer with diagrams, trade-offs, and cost/operational considerations.
- Walk through a specific example end-to-end.
