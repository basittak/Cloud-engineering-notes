# Python

Python is my go-to for automation and small web apps. These notes cover the essentials plus how to use Python with cloud SDKs like boto3.

How to use this folder
- Start with `python-basics.md` to set up a virtual environment and run a tiny script.
- Use `python-automation.md` when you want to write scripts that interact with cloud APIs.

Tip: Write small, testable scripts. If a script grows complex, consider wrapping it into a module and adding tests.
