# Git & GitHub

Version control is non-negotiable. These notes are short, practical reminders about Git commands and GitHub collaboration flows.

How to use this folder
- Follow `git-basics.md` until commands feel second nature.
- Read `github-collaboration.md` when you start opening PRs or setting up branch protections.

Practical habit: commit frequently with clear messages and use branches for features. PRs are for both code review and documentation of changes.
