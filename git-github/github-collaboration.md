# GitHub Collaboration

What it is

GitHub provides hosting for Git repositories and collaboration tools like PRs, actions, and issues.

Why it is used

To centralize collaboration, run CI, host docs, and manage projects.

Key concepts

- Pull requests, reviews, and merging
- Issues and project boards
- GitHub Actions for CI/CD
- Branch protection rules

Commands / Examples

- Create a PR through the web UI
- Configure a simple GitHub Actions workflow in `.github/workflows/ci.yml`

Common interview questions

- How do you protect a branch on GitHub?
- What are GitHub Actions and when would you use them?

Troubleshooting notes

- Inspect Actions logs when a job fails
- Check required status checks on PRs
