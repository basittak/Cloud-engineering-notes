# Projects

This is the "laboratory" of the repo. Each template is intentionally small so you can finish it in a short session and then iterate.

How to use this folder
- Pick one project and finish it end-to-end (deploy locally or to a small cloud account).
- After finishing, add a short note to the project README about what went well and what broke — that note helps you retain the learning.

Starter projects include:
- AWS static website
- Dockerized Python app
- Terraform AWS infra skeleton
- Kubernetes manifest for a sample app
- Simple CI pipeline example
