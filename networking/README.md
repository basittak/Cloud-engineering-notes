# Networking

Networking in the cloud can feel abstract at first. I kept these notes practical: the essential concepts, a few commands to practice, and short examples you can try in a terminal.

How to use this folder
- Start with `networking-basics.md` to understand IPs and subnets.
- Try the DNS and Load Balancing notes when you set up a small website behind an ALB or CloudFront.
- Use the VPN notes if you plan to connect a home lab or on-prem network to the cloud.

Tip: Draw a diagram on paper when designing VPCs. Visualizing subnets and routes prevents many mistakes.
